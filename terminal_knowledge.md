# Terminal Knowledge

**Which terminal client did you choose? Why?**

I'm sticking with Windows PowerShell, mainly because it's what I've already been using throughout this internship for every Git command, running Python scripts, and general file management. It's the default terminal on Windows, well supported, and I'm already comfortable with the basics, so there wasn't a strong reason to switch to something else just for this task.

**What customizations (if any) did you make?**

None for now, I'm keeping it at default settings. Since I'm still fairly early in getting comfortable with the command line itself, I'd rather build up muscle memory with the standard setup first before adding themes, aliases, or plugins on top. That's something I can revisit later once I have a clearer sense of which customizations would actually save me time versus just being cosmetic.

**What was the most useful command you learned today?**

Honestly, reflecting back over this internship so far, the command that's mattered most day to day has been the basic Git cycle, `git add`, `git commit -m`, `git push`, since almost every onboarding issue has ended with pushing changes to GitHub. Alongside that, simple file navigation and manipulation commands like `cd`, `dir`, and `Move-Item` have been what I actually use constantly to get files from Downloads into the right repo folder before committing. None of these are advanced, but they're the ones I've actually leaned on the most in practice.
