# VS Code Productivity: Keyboard Shortcuts

## Setup

VS Code is already installed and set up as my main editor throughout this internship (used it for all the Python scripts, Git operations via the Source Control panel, and file editing so far).

## Top 10+ shortcuts

### Navigation
1. **Ctrl+P** — Quick Open, jump straight to any file by typing its name instead of hunting through the file tree.
2. **Ctrl+Shift+E** — Focus the Explorer (file tree) panel.
3. **Ctrl+Tab** — Cycle between currently open tabs/files.
4. **Ctrl+G** — Jump straight to a specific line number in the current file.

### Editing
5. **Ctrl+D** — Select the next occurrence of the current word (great for renaming a variable used a few times without a full find/replace).
6. **Alt+Click** (or **Ctrl+Alt+Down/Up**) — Multiple cursors, click in several places and type once to edit all of them simultaneously. This is the one that saves the most time once it clicks.
7. **Ctrl+/** — Toggle comment on the current line or selected block.
8. **Alt+Up / Alt+Down** — Move the current line up or down without cutting and pasting.
9. **Ctrl+Shift+K** — Delete the current line entirely.

### Debugging
10. **F5** — Start debugging (runs the file with the debugger attached, breakpoints active).
11. **F9** — Toggle a breakpoint on the current line.
12. **F10 / F11** — Step over / step into, moving through code one line (or one function call) at a time while debugging.

### Terminal Commands
13. **Ctrl+`** (backtick) — Open or focus the integrated terminal without leaving the editor.
14. **Ctrl+Shift+`** — Open a new terminal instance (useful for running a script in one and keeping Git commands in another).

## Reflection

**Which shortcuts do you think will be the most useful in your daily work?**

Multiple cursors (Alt+Click / Ctrl+Alt+Down) is the standout, most of my scripts so far have repeated small edits (renaming a variable, updating several similar lines), and doing that as one action instead of one edit at a time is a genuine time saver. Ctrl+P for quick file jumping and Ctrl+` for the terminal are the two I'll likely use constantly just by default, since almost every task so far has meant switching between editing a file and running it or pushing to Git.

**How can keyboard shortcuts improve your productivity?**

Mainly by cutting out the small friction of reaching for the mouse for things that happen dozens of times a day, opening a file, jumping to a line, running the terminal. Individually each one saves a few seconds, but across a full day of coding those seconds add up into a noticeably smoother flow, less breaking concentration to go click through menus, more staying in the actual thinking/coding rhythm.
